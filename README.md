# Earth Information Jukebox
### NASA Challenges 2026

**Transforming Earth's data into sound. Making our planet accessible through hearing and sight.**

## About the Project

Earth Information Jukebox is an accessibility-focused project developed for NASA Challenges 2026. It transforms Earth and environmental information into meaningful auditory experiences, allowing users to explore and understand our planet through sound and voice-guided interaction.

The project aims to make Earth science more inclusive by providing an experience for both visually impaired and sighted users.

## Key Features

- **Earth Data Sonification:** Transforms Earth visualizations and environmental information into meaningful sound experiences.
- **Live Weather Information:** Retrieves real-time weather information through a live weather data service.
- **Location-Based Search:** Allows users to explore weather information for different cities, countries, and regions.
- **Voice-Guided Experience:** Provides spoken weather reports covering temperature, wind, and humidity.
- **Accessibility-Focused Design:** Supports visually impaired users through accessible interactions.
- **Interactive Interface:** Combines visual exploration, sound, and voice-guided information.

## Accessibility

Accessibility is a fundamental part of Earth Information Jukebox.

The project focuses on:
- Screen reader compatibility.
- Keyboard navigation.
- Voice-guided interactions.
- Meaningful audio descriptions.
- Access to environmental information without depending entirely on visual content.

The goal is to make exploring Earth information an inclusive experience for everyone.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo Weather API
- Web Audio API
- Accessibility technologies

## How It Works

1. Users interact with the Earth Information Jukebox interface.
2. They explore Earth visualizations and environmental information.
3. The system transforms selected information into sound-based experiences.
4. Users can search for locations to retrieve live weather information.
5. The voice-guided experience communicates temperature, wind, and humidity.
6. Accessibility features support navigation through visual and auditory interaction.

## Project Vision

Our vision is to make Earth science accessible beyond visual boundaries.

Earth Information Jukebox explores how sound can provide an alternative way of experiencing our planet, transforming scientific information into an interactive and inclusive experience.

**Understanding our planet should not depend on the ability to see it.**
